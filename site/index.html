功能

小而完整的三件事

不做知识库、不做聊天窗。只把"在原文旁边说一句"这件事做顺手。

划线即评论

选中文字，右键「添加评论」。评论卡片挂在右侧面板，和原文水平对齐，滚动时跟着走；正文里只留一段淡黄高亮和一枚小数字。

@ 一个会话

打 @ 就能点名一个正在跑的 Claude Code / Codex 会话，或者直接「用新会话回答」——插件会在终端里替你开一个。它读完上下文，把回复写回文档。

未读一眼看清

别人（或 AI）的回复带红点，面板顶部常驻「N 条评论 · M 未读」。看完点一下「标为已读」，自己写的永远不算未读。

{==留存在第二周掉了 18%==}{>>yyt|2026-09-05|question: 这个数字来源是哪？[@新会话1](agent:3f9a12c0)<<}

评论就是这样一行文本，紧挨着原文存在 .md 里。没有数据库、没有 sidecar；Git 能 diff，同步不会丢，卸载插件也还能读。

@ 是怎么工作的

三步，留言变成一次真实对话

AI 不是嵌在插件里的黑盒，而是你终端里那个有记忆、有上下文的会话。

1

你 @ 了一个名字

发送时插件把留言、划线原文、文档路径写成一封信，投进这个会话的信箱。在跑的会话下一次开口就会看到；没在跑的，自动在终端启动。

2

会话读信、看文档

首次安装时插件会帮你装一个 Claude Code hook：信到了就注入到会话里，它需要什么上下文就自己去读，不用你复制粘贴。

3

回复写回原位

会话按格式把回复追加到那条评论之后，面板里立刻出现新卡片和红点。你继续在评论里 @ 它，对话就接着往下走。

安装

两分钟装好

从社区插件市场

在 Obsidian 设置 → 第三方插件 → 社区插件里搜「Inline Comments」；或者点上面的黄色按钮直接跳过去。上架前也可以用 BRAT 抢先装，之后会自动更新：

  1. 1社区插件里搜 BRAT，安装并启用
  2. 2命令面板运行 BRAT: Add a beta plugin，粘贴 IvyYang1999/obsidian-inline-comments
  3. 3启用「划线评论」，右侧栏出现 💬 图标；选中任意文字右键就能评了

想用 @ 会话：打开「管理成员」，一键安装 hook，或者直接在评论里 @ 一个新名字。

FAQ

常见问题

评论存在哪里？换台电脑还在吗？

就存在笔记本身，紧挨着被评论的那句话，是一段 CriticMarkup 风格的纯文本。随 iCloud / Git / Obsidian Sync 一起走，不需要额外同步任何东西；没装插件的地方打开也能看到原文。

不用 AI，只当普通评论工具行吗？

完全可以。划线、留言、回复、已读未读，这些都不需要任何会话或联网。@ 只是一个可选项，不用就不会出现在面板里。

@ 的到底是什么？

是你电脑上一个真实的 Claude Code（或 Codex）会话：有自己的 session id、终端窗口和记忆。插件把留言投给它、它把回复写回文档。你随时可以走到终端里接着聊，或者在评论里再 @ 它。

会把我的笔记发到哪儿去吗？

插件本身不联网。投信是往本地一个文件夹里写文件，会话是在你自己的终端里跑；笔记出不出机器，取决于你自己配的 AI 工具，和这个插件无关。

手机上能用吗？

划线评论、回复、已读在手机上都能用。@ 启动终端会话这件事只在桌面端（macOS / Windows）发生——手机上 @ 的留言会等你回到桌面时再送出。

和我的主题合得来吗？

面板所有颜色都是从当前主题的文字色和背景色推出来的，明暗主题、半透明主题都试过。面板底色还可以在设置里单独改。
